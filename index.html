Tagger PNG

Metadatazione IPTC/XMP di immagini PNG per archivio Panini

1. Carica i PNG

Trascina qui uno o più file PNG, oppure clicca per selezionarli.

Trascina i file PNG qui
oppure clicca per sceglierli

2. Compila i campi IPTC

Puoi digitare un testo fisso oppure usare i segnaposto (stessa sintassi di ACDSee) per compilare automaticamente i campi in base a nome file, cartella o numero progressivo.

Segnaposto disponibili — clicca per inserirli nel campo attivo
Il nome di chi ha compilato o revisionato la didascalia (IPTC Writer/Editor)
Separate da virgola. Ogni keyword può contenere a sua volta un segnaposto.
Anteprima (primi file del lotto)

3. Scrivi i metadati e scarica

I file originali non vengono modificati: riceverai copie taggate, singolarmente o in uno ZIP se sono più di uno.
